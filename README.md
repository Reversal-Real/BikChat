## How to Install

Have **Python** (at least 3.14? Unsure about earlier versions but untested)
The server must be online, and it's ran by Reversal/Bik/Me/Idk
1. Download the latest release from the **Releases** section.
2. Extract the BikChat folder (DON'T BE LIKE HELLOZ. BE SMART.)
3. Install Pillow by using `pip install pillow` in CMD.
4. Change your username in `username.txt`.
5. Run `client.py`.

The archive starts on V7 because I deleted any version below that in my PC after making V7.
